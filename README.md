# 小红花统计器

给老师用的本地班级月度统计小工具，分为首页、数据管理、统计报表和设置页面。先在设置中准备班级与学生名单，再在数据管理中创建“班级＋月份”统计，之后才能录入小红花。首页汇总所有班级和月份；单条统计可打开独立报表查看明细。

界面会自动跟随电脑或手机的深色 / 浅色外观设置。统计记录以班级和月份为单位，允许改月份、删除记录；单人登记只更新该统计下对应学生的数量。首页展示全局登记总数、跨月趋势、班级对比和最近统计；独立报表展示该统计的数量分布、排名、学生明细与本班趋势。

## 启动

需要 Python 3.9 或更新版本，不需要安装第三方依赖。

```bash
python3 backend/server.py
```

然后在浏览器打开 <http://127.0.0.1:8000>。按 `Ctrl+C`（macOS：`Control+C`）停止服务。统计数据保存在 `backend/flowers.db`。

## 页面流程

- **设置**：添加班级，再选择班级导入 `.xlsx` 或 `.csv` 学生名单。姓名列必需，序号 / 学号和性别列可选。导入会替换此班级名单；若已有已录入的小红花数据，系统会拒绝替换以保护历史记录。
- **数据管理**：选择已导入名单的班级和月份，创建统计。同一班级每月只能有一条统计。已创建的统计可以编辑班级 / 月份（已有录入数据时不可换班级）、删除，或打开独立报表。
- **录入 / 修改**：从数据管理或报表进入，输入名单序号，核对姓名，填写本次统计数量并确认保存。重新录入会覆盖该学生本次统计中的旧数量。
- **统计报表**：查看一次统计的总数、完成进度、平均数、中位数、众数、分布、排名、学生明细和历史趋势；可导出 CSV 名次表并编辑学生数量。

## 班级名单

首次启动会创建“一（1）班”，并将 `backend/students.json` 中的项目默认名单载入该班。添加其他班级和导入名单请在“设置”页面完成。统计数据保存在 `backend/flowers.db`。
