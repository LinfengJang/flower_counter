# 小红花统计器

给老师用的本地班级月度统计小工具。学生先数好自己的小红花，老师按名单录入或粘贴一列数量；保存后自动生成班级总数、录入进度和前十名月榜。不同月份分别保存。

界面会自动跟随电脑或手机的深色 / 浅色外观设置。月榜页可批量录入；也可进入“单人快速录入”，按名单学号确认姓名后登记数量。单人保存只更新该同学当月的记录，不影响其他同学。

## 启动

需要 Python 3.9 或更新版本，不需要安装第三方依赖。

```bash
python3 backend/server.py
```

然后在浏览器打开 <http://127.0.0.1:8000>。按 `Ctrl+C`（macOS：`Control+C`）停止服务。统计数据保存在 `backend/flowers.db`。

## 录入

- 在名单中输入每位学生本月的小红花数量，按上下方向键切换学生。
- 也可以点“粘贴一列数量”，将电子表格里按名单顺序复制的一列数字粘贴进去。
- 点“保存本次统计”后数据按所选月份保存；再次打开该月份会显示已保存数量。
- 单人登记：打开月榜页右上角的“单人快速录入”，输入名单学号并按回车，核对姓名、填写数量，再点“确认并保存”。
- 点“导出本月统计表”下载包含全班名次的 CSV 文件，可用 Excel 打开。

## 班级名单

首次启动会从 `backend/students.json` 创建班级名单。当前默认名单取自项目附带的“一（1）班学生名单.xlsx”。如要调整班级，可先停止服务并删除 `backend/flowers.db`，修改 `backend/students.json` 后重新启动。注意：删除数据库会同时删除已录入的月度数据。
